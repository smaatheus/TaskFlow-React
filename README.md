# TaskFlow - Gerenciador de Tarefas Full Stack

Lista de tarefas completa com **React**, **Express** e **PostgreSQL**.

## 🛠️ Stack Tecnológica

| Frontend     | Backend    | Banco      | Ferramentas |
| ------------ | ---------- | ---------- | ----------- |
| React + Vite | Express.js | PostgreSQL | Git/GitHub  |

## ✨ Funcionalidades

✅ **Adicionar** novas tarefas com prioridade (Baixa/Média/Alta)  
✅ **Editar** tarefas existentes  
✅ **Marcar como concluída** (persistente no banco)  
✅ **Excluir** tarefas individuais  
✅ **Limpar tarefas concluídas**  
✅ **Persistência completa** no PostgreSQL  
✅ **Interface responsiva**  
✅ **Resumo** de tarefas pendentes/concluídas

## ⚙️ Instalação

Clone o repositório:

```bash
git clone https://github.com/smaatheus/TaskFlow-React.git
cd TaskFlow-React
```

### Backend

```bash
cd backend && npm install && node server.js
```

Servidor rodará em: http://localhost:3001

### Frontend (novo terminal)

```bash
cd frontend && npm install && npm run dev
```

Aplicação disponível em: http://localhost:5173
